# 风格基准（主表②）— ZeldaLike 顶视角RPG

> 本文件锁定角色定妆特征与技术规格，后续批量生成素材（图集帧、切图、动画）以此为准。
> 定妆图：`villager_lookdev_front.jpg`（2026-10-16 确认，草稿存工作区外临时目录，不入库）。

## 画风关键词

- Chibi 大头小身（头约占全身高 45%），粗黑描边
- 平涂赛璐璐 2-3 档阴影，鲜艳饱和色
- 像素质感、硬边缘（非模糊插画感），对齐 Tiny Swords 素材包（与 Pawn/Warrior/Archer 同画面共存不违和）
- 白底精灵，无地面投影（投影由场景 Shadow 资源另铺）

## 角色定妆特征

### 村民 Villager（发布任务 NPC）

| 部位 | 特征 |
|---|---|
| 五官 | 黑点眼、粉色腮红、微笑；棕色短发从帽沿露出 |

| 与商人差异 | 商人=黄衣金发无帽；村民=绿衣草帽挎包，剪影+配色双重区分 |

### 其他角色（暂无新增需求）

- 玩家 / 商人 / 敌人沿用 Tiny Swords 现有素材，不重新生成。

## 各角色 cell 尺寸与参考身高

- 村民 `Villager_Idle`：**454x686 px/帧**，6 帧横排成表 2724x686（2026-10-16 实测）
- 参考身高对齐：村民净高 **1.179 世界单位** ≈ 商人/Pawn **1.180**（Pawn 原始净高 59px @PPU50）
- 同角色所有动作 cell 一致（454x686）

## Pivot 与 PPU

- Pivot：`(0.5, 0.5)` 中心（对齐现有村民/商人 NPC，与场景布局兼容）
- PPU：村民图集为 **553**（= 652px 净高 ÷ 1.18 单位，使 AI 高分辨率图集与 Pawn/商人等高；**Pawn/商人本体仍为 50**）
- 像素对齐：生成图先按 4px 块 nearest 对齐网格再入库，消除抗锯齿矢量感

## Unity 导入设置

- Texture Type：Sprite (2D and UI)；Sprite Mode：Multiple
- Filter：Bilinear；Compression：按平台默认（PC 不高于 2048）
- Mipmap：关闭；MaxSize：1024（单角色图集够用）
- 关闭 Generate Physics Shape（NPC 用独立 CircleCollider2D，不依赖精灵轮廓）

## 动画规格（对齐现网）

- `Villager_Idle`：6 帧、10 FPS、循环（对齐现有 `Villager_Idle.anim`，控制器无需改）
- 时长 ≈ 0.6s；动画仅含 m_Sprite 曲线，替换图源即完成换形象
