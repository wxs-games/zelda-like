## 软件主要功能（定稿，1023 字）

本软件是一款运行于Android 移动平台的俯视视角二维动作冒险游戏。玩家操控角色
在森林等户外场景中自由探索，运用近战挥砍与弓箭射击两种攻击方式击败敌人、
收集资源、完成委托任务，并通过技能树系统逐步提升角色能力，最终达成关卡推进目标。

**研发背景**：移动端碎片化使用场景要求游戏具备随时中断、随时续玩的能力，
而传统PC 端动作游戏普遍缺少可靠的进度持久化机制，玩家退出后进度丢失、
体验断裂。本软件围绕「随时可停、随时可续」这一核心诉求进行设计，
将游戏状态的完整持久化作为基础能力，在架构层面予以保证。

**核心架构**：软件采用泛型状态机、脚本化配置资产与事件解耦相结合的三层架构。
底层为配置层，物品、技能、任务、对话节点等策划数值全部定义为独立的
可脚本化资产对象，由聚合数据库统一索引，数值调整无需改动代码。
中间为逻辑层，角色控制与敌人智能均复用同一套泛型状态机框架，
通过实现状态基类的进入、退出与逐帧更新接口完成行为扩展，
新增状态对既有代码无侵入。上层为系统层，输入、存档、对话、任务、技能树
与移动端适配等横切能力集中管理，通过 C# 事件与下层通信，
避免直接引用造成的耦合。

**技术实现**：角色控制采用刚体速度驱动方式实现移动，配合碰撞体检测系统
保持一致性，并引入输入时间窗口提升操作手感。战斗系统区分挥砍与射击两条
攻击路径，挥砍具备连段判定与分段特效，射击采用蓄力释放机制，
命中后依次完成伤害结算、击退反馈与死亡判定。敌人智能由巡逻、追击等
状态构成，通过距离与视野角度双条件探测玩家，发现目标后切换追击，
丢失目标后返回巡逻。任务系统以任务节点与目标类型组织，
通过监听战斗与交互事件推进目标计数并串联任务链。技能树系统管理可用点数分配，
技能间通过前置关系构成有向无环图，开局自动解锁无前置的根技能，
某技能满级时仅解锁以其为前置的分支，防止越权解锁无关技能。
持久化模块将游戏状态序列化为 JSON 文本写入应用私有目录，
覆盖玩家属性、背包内容、技能等级、任务进度与场景坐标，
读档时按索引逐段还原，并在写入玩家坐标后清零刚体速度，
避免残留动量导致跨场景读档位置漂移；应用切至后台或退出时自动触发存档。
移动端适配模块设置目标帧率上限、关闭垂直同步、禁用系统休眠、
启用多点触控，并在暂停与焦点回调中依据暂停前的界面状态决定是否恢复时间缩放，
避免恢复时误关对话面板，同时按屏幕安全区调整界面边距以适配异形屏。

本软件已具备完整的移动端构建与发布能力，采用 IL2CPP 脚本后端，
同时支持 ARMv7 与 ARM64 两种指令集，输出可直接安装运行的安装包。

## 技术特点（定稿，473 字）

本软件在技术实现上具有以下特点。

其一，策划数值与运行逻辑彻底分离。物品、技能、任务、对话等内容均以独立的
可脚本化资产形式定义，并由编辑器侧的构建器扫描生成聚合数据库，
自动过滤无效占位资产并建立按标识与名称的双向索引，
使配置调整与代码改动解耦，显著降低迭代期的缺陷引入概率。

其二，状态机框架在角色与敌人两类实体间复用。通过泛型参数约束状态基类与
上下文类型，角色控制与敌人智能共用同一套调度框架，
新增行为状态仅需实现约定接口，对既有代码无侵入修改。

其三，系统间通信采用事件驱动机制。任务进度变更、生命值变化等状态更新
以事件形式向外发布，界面层与智能层作为订阅方独立响应，
发布方无需感知订阅方存在，可独立迭代。

其四，持久化结构与业务逻辑解耦。存档数据类为纯数据载体，
读写逻辑集中于统一的存档系统，新增可持久化内容只需扩展数据字段并补齐
读写两处对应逻辑，读档时对各数据段按索引逐段还原，
并针对物理引擎的动量残留做了显式清理，保证跨场景恢复的位置准确性。

其五，移动端适配覆盖完整。围绕帧率控制、后台暂停与自动存档、屏幕安全区
适配、多点触控与虚拟摇杆等移动端特有问题提供了统一解决方案，
其中后台恢复逻辑会依据暂停前的界面状态决定是否恢复时间缩放，
避免了恢复时误关对话或背包面板的体验问题。
