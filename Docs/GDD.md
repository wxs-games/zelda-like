# 游戏设计文档（GDD）

> **这是通用模板**：章节骨架与写法粒度可直接复用，所有 `{{…}}` 与 `【填写：…】` 均为待填占位。
> 装配到具体工程后逐项替换；`示例` 列给出写法参考，替换时请删除。
> 版本：v0.1（模板） | 关联文档：TDD.md（技术方案）、specs/（逐功能规范）

**占位符约定**

| 记号 | 含义 |
|---|---|
| `{{游戏名}}` | 你的项目名称，全篇统一替换 |
| `{{…}}` | 需要按你的项目填写的短语 |
| `【填写：…】` | 需要成段撰写的内容，括号内是写作要求 |
| `（示例：…）` | 写法参考，填完后删除 |

## 二、玩法走读（60~120 秒样例）

【填写：用一段话按时间顺序描述玩家开局 1~2 分钟的实际体验，串起：起始情境 → 第一个目标 → 第一次操作反馈 → 遇到的第一个选择/分叉 → 获得的信息 → 小成功。
