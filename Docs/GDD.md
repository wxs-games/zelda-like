## 一、设计首页

| 区域 | 内容 |
|---|---|
| 项目一句话 | 玩家扮演一名星际环保员小队成员，在横版星球场景中奔跑跳跃、净化污染、对抗污染生物，逐步恢复三颗星球的生态 |
| 游玩条件 | 单人 / PC（Windows）/ 键盘手柄 / 单关 10~15 分钟 / 共 3 关 |
| 玩家承诺 | 用"净化喷壶"清理污染的可动性 + 面对污染生物的横版动作挑战 |
| 设计支柱 | 1. 环保行为即核心动作（净化不是过场动画，是玩法本身）2. 难度随污染程度递进（场景越脏，敌人越强）3. 教育内容融入场景（提示牌/NPC，不做说教弹窗） |
| 反例校准 | 拒绝"资源建造经营"玩法（偏离动作冒险）；拒绝纯问答式环保教学（破坏节奏） |
| 核心动词 | 跑、跳、攻击（夹钳）、净化（喷壶） |
| 循环一句话 | 探索受污染区域 → 清理垃圾/击败污染生物获得净化值 → 净化值解锁通路/削弱敌人 → 到达净化核心完成关卡 |
| 当前范围 | 3 个关卡 + 1 个 Boss + 3 种小怪 + 1 种防御塔；明确不做：多人、开放世界、塔防经营 |

## 二、玩法走读（60~120 秒样例）

玩家降落在第一关星球表面（目标：清理眼前垃圾堆）→ 看到 HUD 上净化进度 34% → 前方塑料袋怪（Enemy01）缓慢逼近，玩家用夹钳攻击两下击退，靠近垃圾堆按互动键喷洒净化 → fx_purify 特效亮起，进度 +5% → 遇到分叉：上层平台有提示牌（讲塑料污染），下层有被垃圾堵住的风扇通路 → 玩家选择先读提示牌，获得"污染生物惧怕净化剂"的知识 → 用喷壶蓄力攻击一次清掉挡路垃圾，通路打开 → 小成功：净化值过半，场景背景色从灰暗转向清新。

## 三、核心机制

### 3.1 基础规则
- 移动：左右跑动（Run）、跳跃（Jump）、下落与落地（Fall/Land），支持土狼时间与跳跃缓冲（手感窗口各 0.1s）
- 攻击：近战夹钳（Attack01，fx_slash），三段连击第三段击退
- 净化：喷壶喷射（消耗净化剂，fx_purify），对垃圾堆/污染源长按 2 秒完成净化；对污染生物造成持续伤害但消耗加倍
- 生命：玩家 5 点 HP（Player_Hurt/Die），受伤无敌 1 秒；死亡回检查点
- 胜负：关卡内净化值达 100% 且击败守关敌人 → 过关；HP 归零 → 回检查点重来

### 3.2 进阶系统
- 净化剂经济：地图拾取 + 击败敌人掉落，净化与蓄力攻击消耗（资源抉择）
- 检查点：净化过的净化塔自动激活（复用 Tower 美术的 Disable→Idle 状态）
- 污染度：全关污染源未清理的比例影响场景色调与敌人刷新频率（支柱 2 的落地）

### 3.3 难度与节奏
- 第一关：慢速 Enemy01 + 简单跳跃平台，教学化
- 第二关：Enemy02（远程毒气，fx_gas）+ 陷阱解救互动 + 水流解谜
- 第三关：Tower01 防御塔（Fire 状态弹幕）+ Enemy03（Chase 追击型）+ Boss01 三阶段战

## 四、内容系统

### 4.1 角色/单位（美术已就位 ✓）
| 单位 | 动画集 | 定位 |
|---|---|---|
| 玩家 | Idle/Run/Jump/Fall/Land/Hurt/Die/Attack01/Interact | 主角，背净化喷壶背包 |
| Enemy01 塑料袋怪 | Idle/Move/Attack/Hurt/Die | 慢速近战，第一关 |
| Enemy02 毒气怪 | Idle/Move/Attack/Hurt/Die | 远程毒气，第二关 |
| Enemy03 追猎者 | Idle/Chase/Attack/Hurt/Die | 发现玩家后高速追击，第三关 |
| Tower01 污染塔 | Idle/Fire/Disable | 固定炮台，可被净化关闭 |
| Boss01 泄漏核心 | Idle/Move/AttackA/AttackB/Hurt/Die | 第三关 BOSS，双攻击技能 |

### 4.2 关卡
1. 污染初现的星球 —— 教学 + 轻度战斗（星球表面散落垃圾，工厂排放废气，教学跑跳互动与净化流程）
2. 生态失衡的森林 —— 解救动物 + 解谜（枯萎森林，被困动物，陷阱解除，有毒植物敌人）
3. 能源工厂的危机 —— 高强度战斗 + Boss（工厂内部，机器人与防御塔，最终 Boss 战）

### 4.3 道具
可回收垃圾桶（净化剂补给）、空气净化装置（区域减速敌人）、能量核心（HP 补给）、剧情收集品（环保知识卡片）

## 五、界面规划
- HUD：HP（心形×5）、净化剂条、净化值进度条、当前目标提示
- 全屏界面：主菜单、暂停、设置（音量/画质）、关卡选择、结算（净化值评级 S/A/B/C）、图鉴（收集的知识卡片）
- 对话框：NPC 对话（逐字显示 + 头像位）、提示牌阅读界面

## 六、音效与音乐
- BGM：主菜单 1 首 + 每关 1 首（污染度影响混音亮度）+ Boss 1 首
- 音效清单：跳跃/落地/攻击命中/喷射/净化完成/受伤/敌人死亡/拾取/UI 点击
- 环境：第一关工厂低鸣、第二关风声鸟鸣、第三关机械运转声

## 七、视觉风格
- 2D 横版，手绘卡通（现有美术：明亮色块 + 粗描边）
- 主色板：自然绿（未污染）↕ 灰紫（污染），场景随净化值插值过渡
- FX 清单（美术已就位 ✓）：fx_dust_run / fx_explode / fx_gas / fx_hit / fx_purify / fx_slash
